# 逐词 · 六级翻译

适合手机使用的六级翻译练习网页，收录 2023 年 12 月至 2026 年 6 月最近六次考试的 18 个翻译主题。

[打开学习网页](https://zhfang28-code.github.io/cet6-translation/)

## 使用

- 按年份或关键词查找真题主题，进入逐句精读。
- 分别控制逐词中文和整句中文的显示。
- 点击英文词，查看语境释义、听发音、加入错词本或练习拼写。
- 拼写答错或选择“还不会”后，单词自动加入错词本。同词合并，累积答错次数。
- 错词本支持复习、掌握标记和移除。学习记录保存在当前浏览器，可通过设置导出、导入 JSON 备份。
- 首次联网加载并完成缓存后可离线使用。朗读由浏览器和设备语音服务提供。

## 内容与来源

共 18 篇、119 个完整英文句子、1,784 个逐词释义。每篇保留至少两个真题来源链接，按考试时间和主题识别。

英文为依据真题信息独立编写的学习参考译文，逐句中文为配套学习释义。原题中文可通过每篇底部的来源链接查看。翻译允许多种表达，拼写练习以当前学习译文的词形为准。

逐词释义说明当前语境下的词义或语法作用。冠词、介词等不能简单替换成中文后拼成整句。数字也提供中文读法。

## 本地运行

需要 Node.js 20 或更新版本，无需安装第三方依赖。

```sh
npm start
```

打开终端显示的本地地址。完整功能通过 HTTP 或 HTTPS 使用。

```sh
npm run build:data
npm run check
npm test
```

`research-*.json` 保存带来源的学习句子和词义，`tools/build-data.mjs` 检查词数对应后生成 `data.js`。`tools/check.mjs` 检查六次考试覆盖、完整句子、逐词中文与来源。

## GitHub Pages

在仓库的 **Settings → Pages** 中，选择 **Deploy from a branch**，分支 **main**，目录 **/(root)**，保存后即可发布。

所有资源使用相对路径，适配 GitHub Pages 项目子目录。无需服务器、账号注册或数据库。
